## About

This is a **Web Development Learning Website** created as part of my journey to learn modern web technologies.  
The goal of this project is to provide a simple, beginner-friendly website where I practiced and showcased the skills I learned during my web development studies.  

Through this project, I explored:  
- **HTML** → structuring web pages  
- **CSS** → styling and layouts  
- **Bootstrap** → responsive design with ready-to-use components  
- **JavaScript** → adding interactivity and dynamic behavior  
- **Angular** → building scalable and modern single-page applications  

This project reflects the learning process and serves as a foundation for future, more advanced projects.
